# YZSCHROS UI/UX 审查报告

> 审查日期: 2026-05-11
> 审查页面: 登录、Dashboard、候选人、客户管理、面试管理、设置
> 方法: gstack browse 截图 + UI/UX Pro Max 设计基准对比

---

## 总体评分: 6.5/10 — 功能完整，细节欠打磨

系统在架构和信息层级上做得不错，暗色主题基调统一。但在视觉打磨、交互反馈、和一致性上还有不少问题。

---

## Critical 级问题 (必须修)

### C1: 漏斗图全零无提示
**位置**: Dashboard
**问题**: 漏斗图所有数据为 0 时，图表直接显示空柱状，没有任何"暂无数据"提示。用户不知道是系统坏了还是真的没数据。
**修复**: 数据全零时显示空状态组件（插画 + 文案 + 引导按钮）。

### C2: 操作按钮视觉太弱
**位置**: 候选人列表
**问题**: "加入分组"、"备注"等行内操作按钮背景色和文字色对比太低，几乎融入背景，用户难以发现它们是可点击的。
**修复**: 提高按钮对比度，加 hover 状态，或改用带底色的 chip 按钮。

---

## High 级问题

### H1: 刷新按钮图标不直观
**位置**: Dashboard 右上角
**问题**: 刷新按钮使用 "C" 图标，不是通用的循环箭头。用户无法直觉理解这是刷新。
**修复**: 替换为 `RefreshCw` (Lucide) 或 `ReloadOutlined` (Ant Design)。

### H2: 候选人卡片信息密度过高
**位置**: 候选人列表
**问题**: 每行候选人的信息（姓名、年龄、学历、经验、时间线、标签）堆在一行里，视觉层级差，扫视困难。
**修复**: 分组信息：左侧主信息区（姓名+当前公司+职位），右侧次要信息（学历、经验年限），标签单独一行。

### H3: 面试日历空状态太弱
**位置**: 面试管理
**问题**: 7 天日历全部显示"暂无面试"，浅灰文字在暗色背景上几乎不可见，缺乏引导感。
**修复**: 空状态用稍大的字 + 描述文案，或显示引导性内容（如"点击排期按钮创建面试"）。

### H4: 移动端左侧边栏不适合触控
**位置**: 全局
**问题**: 移动端 (375px) 使用左侧边栏导航，不适合单手操作。行业标准是底部 Tab Bar。
**修复**: 768px 以下改为底部导航（最多 5 项核心入口），或添加汉堡菜单收缩侧边栏。

### H5: 次要文字对比度不足
**位置**: 全局
**问题**: 侧边栏未选中项、表格次要文字、标签等使用低对比度灰色文字，可能不满足 WCAG AA 4.5:1 标准。
**修复**: 用对比度检查工具验证，提高次要文字亮度至少到 `#9CA3AF` 或更高。

---

## Medium 级问题

### M1: 快速开始卡片主次不分
**位置**: Dashboard
**问题**: "上传简历"、"添加候选人"等操作卡片视觉权重相同，没有突出最高频操作。
**修复**: 主操作（上传简历）用更大的面积或品牌色背景，其他次要操作用描边样式。

### M2: 筛选栏缺少视觉提示
**位置**: 候选人列表
**问题**: 下拉筛选器没有明确的前缀图标或展开箭头，初次使用时不确定哪些是可交互的。
**修复**: 下拉框加标准箭头图标，激活的筛选用 tag/badge 显示。

### M3: 页面标题层级不够清晰
**位置**: 多处
**问题**: "全链路交付漏斗" 和 "快速开始" 使用相同字重和字号，区分度差。
**修复**: 主标题 30px/Black，副标题 16px/Medium，卡片标题 14px/Semibold。

### M4: 通知角标太小
**位置**: 顶部导航铃铛图标
**问题**: 红色数字角标非常小，容易被忽略。
**修复**: 角标最小 16x16px，数字居中，确保可读。

### M5: 客户管理"查看详情"链接感不强
**位置**: 客户管理表格
**问题**: "查看详情"纯文字样式，没有明确的可点击视觉提示。
**修复**: 改为带下划线的蓝色文字，或用小型按钮组件。

---

## Low 级问题

### L1: 近 30 天标签间距紧
**位置**: Dashboard 漏斗图标题旁
**修复**: 增加标题和时间范围之间的 margin。

### L2: KPI 卡片内间距不一致
**位置**: Dashboard 顶部统计卡
**修复**: 统一 icon、数字、标签的 padding 和对齐方式。

### L3: 企业管理"未知"行业显示
**位置**: 客户管理表格
**问题**: 行业显示"未知"，是数据问题，但 UI 可以用灰色 tag 或横线代替。
**修复**: 空值时显示 `--` 而非 "未知"。

## 设计基准对比

UI/UX Pro Max 对猎头管理系统的建议:

| 维度 | 建议 | 当前状态 | 差距 |
|------|------|----------|------|
| 风格 | Soft UI Evolution (柔和阴影 + 高对比) | 纯平暗色主题 | 缺少层次感和阴影深度 |
| 主色 | #0F172A (深蓝黑) | 当前暗色主题偏灰 | 可适当提升主色纯度 |
| 强调色 | #22C55E (绿色正向指标) | 多色混用 | 应统一强调色语义 |
| 字体 | Fira Sans / Fira Code | 系统默认 | 无特色但功能可用 |
| 图标 | 统一 Lucide 线性图标 | 大部分统一，刷新图标异常 | 修复异常项 |
| 交互 | 150-300ms 过渡动画 | 部分缺失 hover/press 反馈 | 需系统性补充 |

## 优先级排序 (建议修复顺序)

1. **C2** — 操作按钮不可见 → 直接影响用户操作
2. **C1** — 漏斗图空状态 → 直接影响数据理解
3. **H1** — 刷新图标 → 可用性问题
4. **H5** — 对比度 → 无障碍合规
5. **H2** — 候选人卡片 → 核心页面的信息扫描效率
6. **H4** — 移动端导航 → 移动端可用性（如果移动端是优先级）
7. **H3** — 面试空状态 → 非核心但影响专业感
8. **M1-M5** → 打磨项
9. **L1-L3** → 锦上添花
