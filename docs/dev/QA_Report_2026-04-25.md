## Issues

### ISSUE-001: API 启动崩溃 - MatchingModule 依赖注入失败

**Severity:** Critical
**Category:** Functional
**Fix Status:** Verified
**Commit:** unstaged (working tree)

**Root cause:** `matching.module.ts` 的 `MatchingListener` 注入了 `JobService`（通过 `forwardRef`），但 `MatchingModule` 没有 import `JobModule`。

**Fix:** Added `import { JobModule } from '../job/job.module';` and `forwardRef(() => JobModule)` to MatchingModule imports array.

**Verification:** `pnpm dev` starts clean. API responds. Login/register works. All authenticated pages load.

**Files changed:** `apps/api/src/modules/matching/matching.module.ts`

### ISSUE-005: Dashboard 显示错误/空白

**Severity:** High
**Category:** Functional
**Fix Status:** Deferred
**Screenshot:** `screenshots/dashboard.png`

**Repro:**
1. Login successfully
2. Redirected to /dashboard
3. Page shows only "Reload" and "Back" buttons, no dashboard content
4. Console shows 404 errors for analytics API

**Root cause:** Frontend dashboard page requests API endpoints that don't match the backend controller routes (e.g., frontend may request `/api/analytics/dashboard` but backend only has `/api/analytics/overview`).
