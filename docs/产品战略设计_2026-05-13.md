## 核心定位

**内部猎头业务交付工具**，不是 SaaS。先自己用透，再谈商业化。

## 四个前提（已确认）

1. 先跑通一个行业，不铺面
2. 只修阻碍日常数据积累的功能
3. 数据资产是核心竞争力
4. 每个功能必须有 ROI 论证

## 三阶段路线

### Phase A: 数据积累期（1-6 个月）

**目标**: 跑通一个行业的人才数据积累闭环

- 猎头业务交付 — 赚第一桶金
- 人才数据录入 + 简历解析 — 数据沉淀
- 只修阻塞日常使用的功能 Bug
- 不做花哨功能，不做对外销售

**关键指标**: 人才库有效简历数量、单日交付效率提升

### Phase B+C: AI 自动化 + 模型验证（6-12 个月）

**目标**: 用真实数据训练 AI 匹配，验证人才能力模型

- AI 匹配: 基于积累的候选人数据，自动匹配岗位需求
- 能力模型: 从历史交付数据中提取人才能力画像
- LLM 提速: 优化 AI 调用链路（qwen-turbo、并发、截断优化）
- 飞书/邮箱集成自动化

**关键指标**: AI 匹配准确率、人工审核减少比例

### Phase D: 数据变现（12+ 个月）

**目标**: 把数据资产变成收入

- 行业人才洞察报告 — 卖给甲方企业
- 组织诊断报告 — 甲方 HR 决策支持
- 人才模型 API — 行业标准输出

**关键指标**: 数据产品收入占比

## 商业模式总结

```
猎头业务交付（赚钱）→ 数据沉淀（壁垒）→ 模型售卖（暴利）→ 系统出售
```
