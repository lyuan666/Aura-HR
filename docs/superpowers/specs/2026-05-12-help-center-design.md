# 天选OS帮助中心设计

## 目标

在后台系统右上角增加一个 `?` 帮助入口，点击后跳转到应用内 `/help` 页面。帮助中心用于承载完整操作手册，覆盖日常招聘交付流程、模块功能说明、常见问题和排错提示。

## 交互

- 顶部栏在邀请协作成员和通知之间展示 `?` 图标。
- 点击 `?` 后使用 Next.js 路由跳转到 `/help`。
- `/help` 保留现有后台布局：左侧导航、顶部栏和主题风格一致。
- 帮助页面首屏包含标题、说明、搜索框、快速开始区域和模块入口卡片。
- 点击模块入口后在同一页面切换文档内容，页面下方呈现左侧目录和右侧步骤说明。

## 内容范围

帮助中心首版使用静态内置内容，不依赖后端接口。模块覆盖：

- 快速开始
- 仪表盘
- 人才库与简历上传
- 飞书导入
- 客户管理
- 职位管理
- AI 匹配与推荐
- 交付看板
- 邮箱归集
- 合同管理
- 数据报表
- 面试管理
- 系统设置
- 客户门户
- 常见问题

## 架构

- 新增 `/help` 页面，位于 `apps/web/src/app/(app)/help/page.tsx`。
- 新增帮助内容数据模块，例如 `apps/web/src/data/help-center.ts`。
- 修改 `apps/web/src/components/v2/V2Header.tsx`，加入 `?` 图标按钮并跳转 `/help`。
- 不新增后端接口，不新增数据库表。

## 视觉

- 使用现有深色主题、边框、文本颜色和卡片风格。
- 页面保持后台工具属性，避免营销页式 hero。
- 卡片用于模块入口，文档正文采用分栏布局，移动端降级为单列。
- 图标优先使用 `lucide-react`。

## 验证

- `pnpm build:web` 必须通过。
- 线上 `/help` 可访问。
- 顶部栏 `?` 图标能跳转到 `/help`。
- 关键页面 smoke test 继续通过。
